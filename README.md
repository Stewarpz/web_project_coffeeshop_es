# Triple Espresso

## Descripción

Este proyecto es la página web principal de una cafetería de especialidad. Incluye un encabezado interactivo, una sección estructurada para reservaciones y un pie de página con enlaces a redes sociales.

## Tecnologías y Técnicas Utilizadas

- HTML5 (Semántica web y formularios)
- CSS3 (Flexbox, Posicionamiento Absoluto/Relativo)
- Metodología BEM para nomenclatura de clases
